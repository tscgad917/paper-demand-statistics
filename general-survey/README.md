# 總務課通用問卷平台

此資料夾為年度問卷平台前後台，部署於既有 GitHub Pages 專案：

- 填答頁：`https://tscgad917.github.io/paper-demand-statistics/general-survey/`
- 管理頁：由「總務課統一管理中心」SYSTEM 05 進入
- Supabase：沿用主專案 `onebxqajsiqmhfcizaxl`

## 初次啟用步驟

1. 在主 Supabase 專案 SQL Editor 執行本資料夾的 `schema.sql`。
2. 確認既有 `units`、`admin_authorizations` 資料表可由已授權管理員讀取。
3. 由總務課統一管理中心登入，點選「通用問卷平台」。
4. 建立年度問卷、指定填報單位、新增題目及圖片。
5. 檢查填答網址及開放期間後，再按「發布問卷」。

## 第一版功能

- 年度問卷批次管理。
- 沿用既有 `units` 單位資料，依 `id` 排序並可逐份問卷指定填答單位。
- 題型：數量、單行文字、多行文字、單選、多選、日期。
- 題目圖片上傳（JPG、PNG、WEBP，單張上限 5 MB）。
- 年度問卷複製（題目、圖片路徑、選項及填報單位）。
- 填答期間內同一單位可重複提交，以最後一次提交內容為準。
- 截止時間由資料庫 RPC 再次檢查，前端停用不作為唯一安全限制。
- 管理端填報進度及 CSV 匯出（可用 Excel 開啟）。

## 資料安全說明

- 管理端沿用 Supabase Auth session 及 `admin_authorizations` 授權。
- 問卷及回覆資料表啟用 RLS，只有有效管理帳號可直接讀寫。
- 公開填答僅透過兩個受限 RPC 取得已發布問卷內容及提交資料。
- 圖片桶僅供非個資的問卷品項示意圖使用；請勿上傳社員印鑑卡、身分證件或其他敏感個資。
- 本系統不提供匿名填答者的身分驗證；填答單位由問卷指定名單控制，填答人姓名為填報欄位。

## 注意事項

- 第一版不會自動建立或發布 116 年度問卷。管理者需在後台確認年度、填報期間、題目及填報單位後再發布。
- 問卷題目刪除時，該題既有答案也會隨資料庫外鍵規則刪除；請先確認未有正式填答資料。
- CSV 為 UTF-8 BOM 格式，可由 Excel 開啟；不是原生 XLSX 活頁簿。
